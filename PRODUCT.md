## Design Context

### Users
Marc Gomes, ramoneur professionnel (chimney sweep) basé à Grues, Vendée (85). Utilisateur unique — il utilise l'app seul sur son téléphone, en déplacement sur les chantiers, pour saisir et exporter ses rapports d'intervention client. Contexte d'usage : extérieur en plein jour, mains parfois sales, besoin de rapidité.

### Brand Personality
**DSSV — Depuis Sud Vendée** (Ramonage Marc Gomes)
- Logo : cercle avec silhouette ramoneur (haut-de-forme, balai, habit classique)
- Signature script manuscrite "Marc Gomes"
- Palette camion : rouge profond (#BA1E26) + blanc + noir
- Trois mots : **rouge-signature, métier-français, robuste**
- L'app doit faire penser au camion : professionnel, artisan de confiance, couleurs fortes

### Aesthetic Direction
- Fond clair (usage jour, extérieur) avec rouge profond comme couleur d'accentuation
- Mode sombre disponible pour ceux qui préfèrent
- Rouge French crimson (`#BA1E26` light / `#E03440` dark) — ni bordeaux ni rouge pompier
- Neutrals légèrement tintés vers le rouge (cohérence subconsciente avec la marque)
- Typographie web : Barlow Condensed (semibold/bold) pour titres + Figtree (400/600) pour corps
- Typographie native : system fonts iOS (propres, lisibles)
- Anti-référence : aucun design "techy", pas de dégradés, pas de dark mode avec accents lumineux

### Design Principles
1. **Rouge = confiance** — Le rouge est rare et précieux. Il marque les actions principales, les sélections actives, les badges de marque. Jamais décoratif.
2. **Formulaire = outil de chantier** — Dense mais lisible. Labels uppercase petits, valeurs en grand. Efficacité avant esthétique.
3. **Marque visible** — Le nom DSSV / Marc Gomes doit être présent de façon reconnaissable sur chaque écran principal.
4. **Lisible en plein soleil** — Contraste maximal. Fond clair (mode principal), texte foncé.
5. **Artisan, pas startup** — Aucun design "SaaS dashboard". Chaque écran doit ressembler à un document professionnel physique.
